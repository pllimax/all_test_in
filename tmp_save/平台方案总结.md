# 平台方案总结

## 方案

为 SGLang 昇腾 NPU 的每日测试（性能/精度/功能）搭建一个轻量结果看板，解决测试结果散落在 CI 产物中、无法按用例跨日期跟踪的问题。核心思路是**"Git 即数据库、零重依赖"**：CI 机器自动收集结果推送到 Git 数据仓，服务端一个单文件 Python 应用直接读取并提供网页展示，不依赖 Docker/Prometheus 等组件。

## 实现过程

1. **采集端**：CI 机器定时收集性能指标文件、精度评测日志和多机任务日志，按"分支-日期-运行ID"归档，带重试机制推送到数据仓
2. **同步端**：服务器通过 cron 定时拉取数据仓和源码仓（稀疏克隆，仅取用例配置和基线），处理认证、合并冲突等同步问题
3. **展示端**：后端解析数据并聚合 CI job 状态，前端单页表格展示指标趋势、精度结果、通过状态，支持历史展开、趋势图、备注、筛选和导出

## 结果

- 平台已稳定上线，全链路自动化（采集 → 同步 → 展示）
- 一屏可见所有用例的性能趋势、精度结果、功能通过率和 CI 状态
- 支持同一用例在不同软件环境下的独立历史追踪，状态判定规则（如"执行中"优先于阈值判断、无数据不误判失败）经过多轮修正后准确可靠
- 沉淀了线程安全、路径安全、同步防丢数据等健壮性机制，运行稳定
